## 📝Overview
   
    Week 2 covered essential mathematical and statistical foundations for data science, starting with **Descriptive Statistics** and **Probability Theory**, then transitioning into **Linear Algebra** for vector and matrix operations. The week concluded by building practical exploratory data analysis skills in **Seaborn**-learning distribution analysis, non-parametric outlier detection via **IQR method**, correlation heatmaps, and end-to-end data storytelling on real-world datasets.
