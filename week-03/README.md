## 📝Overview

   Week 3 covered a transition from statistical and exploratory analysis to Machine Learning foundations, starting with **Supervised Learning** concepts and the **Scikit-learn API**, then building core predictive models through **Linear Regression** for continuous targets and **Logistic Regression** for binary targets paired with classification metrics for model evaluation. The week expanded into a broader model toolkit; to include **Decision Trees, Random Forests, SVMs, k-NN** algorithms, comparing how each algorithm handles the same classification differently. The week set off by a **Supervised-Learning Mini-Project** applying the full pipeline on a real-world dataset - EDA, preprocessing, model selection and metric driven evaluation.
